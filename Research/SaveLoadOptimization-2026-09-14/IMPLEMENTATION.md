# 세이브/로드 최적화 적용 기록

## 적용 범위

- 저장 스냅샷 수집이 끝나는 즉시 맵 오브젝트 틱 일시정지를 해제함
- 압축과 파일 쓰기를 백그라운드 작업으로 유지함
- 시작 슬롯과 수동 슬롯 파일 읽기·압축 해제·바이너리 파싱을 백그라운드 작업으로 이동함
- GZip 전체 내용을 `MemoryStream`과 `ToArray`로 복제하지 않고 스트림에서 직접 파싱함
- 설치물의 `(placementSequence, itemId)` 위치 인덱스를 추가해 중복 탐색을 정상 경로 O(1)로 변경함
- 맵 상태 캡처에서 임시 딕셔너리 스냅샷 목록 생성을 제거하고 출력 목록 용량을 선할당함
- 컨베이어 아이템 병합과 구형 바닥 아이템 역채우기의 반복 선형 검색을 좌표 인덱스로 교체함
- 설치물 상태 중복 캡처와 컨베이어 역채우기 중복 호출을 제거함

## 영향 범위

- 세이브 파일 포맷 버전은 변경하지 않음
- 기존 v18 대체 읽기 경로와 현재 v61 직렬화 결과를 유지함
- Unity 오브젝트 접근은 메인 스레드의 스냅샷/복원 단계에 남기고, 분리된 데이터의 파일 I/O만 작업 스레드에서 처리함

## 남은 확인

- Unity 에디터와 실제 게임은 실행하지 않았으므로 대형 월드의 저장 프레임 시간, 로드 화면 체감 시간, 메모리 피크는 플레이 모드 프로파일링이 필요함
- `ResourceDepletionSaveHarness`는 기존 `ResourceInstance` 변경으로 추출 대상 멤버를 찾지 못해 테스트 본문 실행 전 중단됨
