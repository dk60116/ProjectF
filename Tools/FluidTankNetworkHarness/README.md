# Fluid tank network harness

`Fluid tank.cs`의 실제 인접 탱크 호환성 메서드와 `Pipe.cs`의 탱크 경계 탐색 메서드를 추출해 실행한다.

서로 다른 출력 유체망에 연결된 인접 탱크가 합쳐지지 않는지, 같은 유체나 비어 있는 탱크는 기존처럼 저장 뱅크를 구성하는지 확인한다. 연결이 거부된 다른 유체 탱크가 탱크 반대편의 정상적인 빈 탱크 연결까지 막지 않는지도 재현한다. 비어 있어도 다른 포트에 연결된 파이프망으로 유체 정체성이 확정된 탱크가 다른 유체 파이프를 거부하는지 검증한다. 탱크 측 유체 식별 검색의 재귀 방지와 파이프–탱크 경계 검사도 함께 확인한다.

블루프린트는 실제 `InstallationPlacementController`의 탱크 연결 시각 갱신·유체 비교·인접 파이프 선택·고정 연결 방향 선택·스냅샷 조회 메서드를 추출해. 네 방향의 빈 탱크·같은 유체·다른 유체 조합과 미리보기·설치된 탱크·저장된 탱크를 확인해. 저장 스냅샷의 유체가 빈 프리팹보다 우선하는지, 양쪽 미리보기가 같은 경계를 표시하는지, 유체 변경 후 재갱신과 기존 탱크–파이프 연결도 검사해. 빈 탱크들이 서로 다른 파이프망이나 제작기 출력에 연결된 경우도 설치 후 실제 탱크의 경계 판정과 비교해. 파이프 쪽은 같은 셀에 고정 출력이 있거나 없는 경로, 현재 미리보기를 조회에서 제외하는 경로도 검사해.

씬 조회·파이프망의 유체 탐색·제작기 출력 조회·렌더러 적용은 테스트 대역이고, 실제 게임 화면은 검증하지 않아.

```powershell
./Tools/FluidTankNetworkHarness/Run.ps1
```
