# 로봇팔 벨트 픽업 우선순위 하네스

```powershell
./Tools/RobotArmBeltPickupHarness/Run.ps1
```

현재 `Block.cs`의 실제 벨트 후보 선택 메서드를 추출해 Unity 관리형 벡터 수학으로 실행한다. 로봇팔 코드가 후보 확인과 실제 제거 모두에 본체 위치를 전달하는지도 검사한다.

- 본체에 가까운 아이템 우선
- 같은 거리에서는 낮은 슬롯 인덱스 우선
- Y 높이는 거리에서 제외
- 필터 유지
- 픽업 가능 반경은 기존 벨트 픽업 지점 기준 유지

Unity 엔진이나 물리·애니메이션을 실행하지 않는다.
