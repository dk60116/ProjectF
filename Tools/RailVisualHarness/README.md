# Rail Visual Harness

```powershell
& ./Tools/RailVisualHarness/Run.ps1
```

Unity를 실행하지 않고 실제 `RailVisualNetwork`, `RailVisualStyle`, `RailBallastMask`와 `Railload`의 메시 생성 메서드를 검사해.

- 한 번 설치·분할 설치·역방향 설치·부분/완전 겹침의 표시 경로 길이와 침목 위치를 비교해.
- 곡선과 순환선, 순환선의 침목 간격·레일 양쪽 이음매, T/Y 분기·교차·자기 교차를 확인해.
- 옆으로 분기하는 선로를 추가해도 직진 선로의 침목 위치와 간격이 유지되는지, 같은 경로가 가까이 돌아와도 침목이 누락되지 않는지 검사해.
- 평행선·높이가 다른 선로·다른 표시 설정을 잘못 합치지 않는지 검사해. 표시 연결 허용 오차는 0.001칸이며 주행용 스냅 반경을 사용하지 않아.
- 삭제·재연결·겹친 선로 하나만 삭제·경로 이동과 전체 삭제, 무관한 연결 구간 캐시의 보존을 확인해.
- 32칸 렌더링 셀 경계에서 침목 간격이 다시 시작하지 않고, 중복 레일 메시가 없어지는지 검사해.
- 침목 면별 정점과 높이·메시 인덱스, 미리보기와 설치 결과의 공통 침목 배치 규칙을 검사해.
- 긴 직선과 촘촘한 곡선이 만나는 불균등 샘플 경로에서 양쪽 레일 윗면 삼각형이 뒤집히지 않는지 정·역방향과 네 회전 방향으로 검사해.
- 자갈 마스크의 정·역방향, 분할 설치·중복·곡선·교차의 합집합, 둥근 끝과 폭을 검사해. 음수 좌표와 지형 구역 경계의 보간용 테두리가 일치하는지도 확인해.
- 철거 시 다른 선로의 자갈은 남는지, 마지막 선로 삭제 후 빈 마스크를 정리하는지, 경로 이동·국소 수정·무관한 구역 캐시 보존을 검사해. 긴 대각선의 구역 수와 변경 없는 10,000회 갱신의 할당도 검사해.
- 네이티브/데이터 레일의 설치·철거 연결, 물 제외, 지형 셰이더의 조명 계산 전 자갈 적용, 런타임 텍스처 경로와 반복·밉맵 설정을 소스 계약으로 확인해.
- 희소 선로 1,000개의 공간 검색과 국소 수정, 변경 없는 10,000회 갱신의 관리 할당을 측정해.

설치된 데이터 레일은 표시 전용 연결망을 사용해. 저장·철거·열차 주행 경로는 바꾸지 않아.
분기에서는 가장 곧게 이어지는 방향의 침목 간격을 유지해. 나머지 분기 팔에만 접합부 여백과 다른 경로 침목과의 근접 검사를 적용하고, 같은 연속 경로의 침목은 근접 검사로 제거하지 않아.
변경된 연결 요소와 그 표시 셀만 재생성해.
동일한 연결 요소가 아주 크면 그 요소의 재계산 비용은 길이에 비례해. 미리보기·편집 중 임시 네이티브 레일은 단독 경로를 표시하며, 확정 후 연결 표시로 전환돼.

소스 계약으로 `RailWorldView`가 연결 경로·공통 침목 좌표를 사용하는지 확인해.
실제 GPU·메시 업로드·Unity 프레임·화면 캡처는 검증하지 않아.
자갈은 별도 메시나 높이 보정 없이 지형 알베도에 그려. `RailBallastMask`는 지형 구역 크기에 맞춰 칸당 16픽셀의 R8 마스크를 만들고, 선로마다 둥근 선분의 최대 피복률을 합쳐. 한 픽셀 테두리는 인접 구역과 같은 월드 좌표로 계산해. `RailBallastTerrainRenderer`는 바뀐 구역의 텍스처만 업로드하고 프로퍼티 블록을 캐시해. 비어 있는 구역의 텍스처는 해제해.
`TerrainBiomeBlend`와 `WorldTriplanar`가 `RailBallastTerrain.hlsl`을 공유하고, 월드 좌표로 `Resources/Textures/RailBallast.png`를 반복해. 물에는 적용하지 않아. 저장·충돌·주행에는 관여하지 않고, 설치 미리보기는 기존 레일·침목 표시를 사용해.
자갈 텍스처는 칸당 0.25회 반복하고, 바깥쪽 0.3칸은 흙으로 점진적으로 섞어. 알갱이에 따른 변형은 가장자리에만 적용하고 중심부에도 지면색을 10% 남겨서 띠 형태의 경계를 줄여.
