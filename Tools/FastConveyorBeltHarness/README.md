# Fast Conveyor belt / Fast Conveyor belt 2F

```powershell
& ./Tools/FastConveyorBeltHarness/Run.ps1
```

`Item_141_Fast Conveyor belt.asset`가 아이템 원본이야. 기본 벨트의 직선·코너·역코너 프리팹을 상속하고 아이템 식별자, 속도와 화살표 머티리얼만 덮어써. 속도는 1.0으로 기본 0.5의 두 배야. 네 개의 고속 상판 재질은 공통 화살표 마스크와 노란색을 사용해.

아이템 ID 중복, 프리팹 상속과 오버라이드 대상, 세 방향의 고속 벨트 참조, 렌더링 캐시의 아이템/재질 연결, 공통 프리팹과 게임 씬의 아이템 등록, 투명 노란 아이콘, 바이너리 제작식과 Resources 복사본 일치를 확인해. ID와 씬 배열 위치는 ItemDefinition과 GUID로 확인하므로 에디터 목록 재정렬을 허용해. 기본 고속 벨트의 제작 비용은 바이너리 원본을 따르고 검사에 고정하지 않아.

`Item_142_Fast Conveyor belt 2F.asset`는 기존 2F 프리팹의 3칸 점유·경사 메시·ConvayorBelt2F 동작을 상속해. 속도는 1.0으로 기본 2F 0.5의 두 배야. 상판과 두 연결부는 기존 `M_FastBeltTop`을 재사용해. 작업대에서 고속 벨트 3개로 고속 2F 1개를 만들어. 별도 런타임 분기와 중복 재질은 추가하지 않아.

직선 렌더링 캐시는 기본 벨트의 동일한 형상에서 재질과 정체성만 바꿨어. 의존성 해시는 비워 두어 기존 에디터 시작/빌드 단계의 archetype baker가 실제 Unity 의존성 해시로 다시 갱신해. 런타임 동작을 분기하는 신규 C# 코드는 추가하지 않았어. Unity 프리팹 임포트·셰이더 출력·게임 화면 검증은 실행하지 않아.
