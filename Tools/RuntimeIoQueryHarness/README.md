# Runtime IO coordinate queries

`powershell -File Tools/RuntimeIoQueryHarness/Run.ps1`

Unity를 실행하지 않고 실제 IO 조회·영역 등록·중첩 필터 메서드를 추출해 검사해. Unity 6000.4의 실제 `HashSetPool`을 참조하고, 씬과 레시피 저장소만 대체해.

- 출력 좌표 밖 10,000개 모듈을 조회하지 않는지 확인
- 유체 출력 전용 좌표 인덱스가 전체 활성 모듈 fallback 없이 동작하는지 확인
- 입력 필터 변경, 빈 허용 집합, 연료와 입력 영역의 합집합, 박스 필터 우선순위
- 비활성, 중복 등록, 이동·복원에 사용하는 등록 경로, 제거와 풀 반환
- 중첩 호출에서 임시 집합이 섞이지 않는지 확인
- 워밍업 후 일반 IO와 유체 출력 조회 각각 10,000회의 관리 힙 할당 0바이트 확인

실제 Unity 씬의 배치·세이브 로드·벨트 수용량 동작은 별도 플레이 검증이 필요해. 이 하네스는 실제 네이티브 씬을 대신하지 않아.
