# Workable ECS 하네스

Workbench, Anvil, Anvilbench의 데이터 인스턴스와 작업 범위 연결을 화면 조작 없이 검증해.

```powershell
./Tools/WorkableEcsHarness/Run.ps1
```

블루프린트 작업 범위 표시의 회귀 검증은 아래 하네스를 사용해.

```powershell
./Tools/WorkableEcsHarness/RunPreview.ps1
```

실제 범위 요청 구성·선택·등록 코드를 추출해 11개 검사를 실행해.
컴포넌트가 비활성화된 미리보기의 표시·이동·다중 선택·제거와 제작용 범위 인덱스에서의 제외,
설치된 작업대의 연결 그룹 표시·중복 제외·풀 정리를 확인해.
Unity 컴포넌트 생명주기와 렌더러는 경계 대역이어서 실제 화면 검증은 별도로 필요해.

실제 `WorkableWorld`, `WorkableInstance`, `WorkableRangeIndex`, 상태 슬롯, 레이 셀 순회,
`TerrainGenerator.Workables`와 편집용 작업대 생성 메서드를 사용해.
Unity 오브젝트 생성, 렌더 템플릿, 저장소, 네이티브 행렬·Bounds 레이 교차는 경계 대역으로 대체해.
게임 FPS나 실제 저장 파일의 직렬화·역직렬화 검증은 아니야.

검증 범위:

- 겹침·변 접촉 연결, 모서리 분리, 부동소수점 경계, 음수 좌표, 배치 순서
- Workbench·Anvil 범위 합집합, 반복 조회 캐시, 연결 작업대 철거·이동·업그레이드 후 그룹 갱신
- 관계없는 그룹의 캐시 유지, 무작위 배치·변경과 전수 그래프 조회 결과 비교
- 데이터 핸들 만료와 슬롯 재사용, 점유 칸 연결, 주변 충돌·카메라 렌더 후보 조회
- 가까운 레이 대상 선택, 만료 대상과 배치 애니메이션 중 숨긴 대상 제외
- 저장 상태 공유, 기존 좌표 상태의 위치 복원, 편집용 오브젝트 전환과 이동 후 데이터 재등록
- 1천·1만·10만 개 연결 범위의 등록·최초 조회·반복 조회·분리 후 재계산 시간과 추가 GC 할당

2026-10-05 검증에서 1,838개 검사를 통과했어.
10만 개 범위는 등록 약 199ms, 최초 그룹 조회 약 80ms, 반복 조회 100회 약 4ms,
중간 작업대 제거 후 그룹 재계산 약 18ms였고 반복 조회의 추가 GC 할당은 0바이트였어.
시간은 실행 환경에 따라 달라져.

재료 조회·차감은 `Tools/PortableOutputHarness/Run.ps1`에서 별도로 검증해.
겹친 범위와 플레이어 주변 재료의 중복 제외, OutputArea·상자 최소 보유량 경로,
멀리 떨어진 범위의 제한된 칸 탐색, 반복 조회의 추가 GC 할당을 확인해.

Unity에서 추가 확인할 항목:

- 세 종류 작업대의 인스턴싱 모델과 실제 회전·충돌
- InteractionButton과 제작 패널의 열림·범위 이탈·닫힘
- 이동·철거·업그레이드·블루프린트와 실제 저장 파일 불러오기
- 제작 등록·취소·환불, 재귀 제작 큐와 범위 표시
