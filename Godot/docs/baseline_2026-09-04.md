# 2026-09-04 성능 기준선

## 측정 환경

- AMD Ryzen Z1 Extreme, 8 cores / 16 logical processors
- AMD Radeon Graphics, driver 32.0.22029.13001
- Windows 11 Home 64-bit, build 10.0.26200
- Godot 4.7.2 stable, Forward+, D3D12
- CPU simulation: MSVC release build
- Rendering: debug GDExtension, 1280×720 hidden benchmark window, VSync off

수치는 이 장비에서 실제 실행한 결과다. CPU 표는 median / p95 millisecond다.

| 100K | 100% | 0.0843 / 0.1475 | 0.1163 / 0.1719 | 8,858,440 |
| 100K | 10% | 0.0816 / 0.1414 | 0.0098 / 0.0115 | 8,858,440 |
| 100K | 1% | 0.0797 / 0.1236 | 0.0010 / 0.0011 | 8,858,440 |
| 1M | 100% | 1.7038 / 2.0509 | 2.1619 / 2.3694 | 88,395,536 |
| 1M | 10% | 1.0398 / 1.3173 | 0.1034 / 0.1313 | 88,395,536 |
| 1M | 1% | 0.9925 / 1.5115 | 0.0095 / 0.0145 | 88,395,536 |

100% active에서는 연속 AoS 순회가 index 간접 접근보다 빠르다. 10%와 1% active에서는 대상 감소 효과가
압도적이다. 따라서 active list는 항상 켜는 미세 최적화가 아니라 실제 sleep 비율이 높은 시스템을 위한 구조다.

`reserved_bytes`는 현재 자체 vector capacity만 합산하며 `unordered_map` 및 표준 라이브러리 allocator overhead는
포함하지 않는다. 1M 결과는 프로세스 전체 메모리가 아니라 core가 추적하는 최소 기준선이다.

원본 CSV는 `native/benchmarks/latest_machine_benchmark.csv`에 있다.

## Static placeholder rendering

카메라가 전체 grid를 포함하도록 구성해 모든 인스턴스가 보이는 상태에서 측정했다.

| Instances | Visible | Batches / draw calls | wall mean | wall p95 | snapshot→MultiMesh rebuild | visibility | upload bytes |
|---:|---:|---:|---:|---:|---:|---:|---:|
| 10K | 10K | 64 | 0.9567 ms | 1.329 ms | 7.061 ms | 0.009 ms | 480,000 |
| 50K | 50K | 196 | 1.4201 ms | 1.766 ms | 8.109 ms | 0.023 ms | 2,400,000 |
| 100K | 100K | 400 | 2.2073 ms | 2.673 ms | 24.509 ms | 0.033 ms | 4,800,000 |

Godot의 `viewport_get_measured_render_time_gpu()`는 이 hidden-window 측정에서 0을 반환했으므로 GPU time으로
해석할 수 없다. wall frame은 같은 실행의 비교 기준으로만 사용한다. GPU 절대 비용은 RenderDoc 또는 화면에
표시된 standalone release build에서 다시 측정해야 한다.

현재 static 상태에서는 buffer를 매 frame 올리지 않는다. rebuild 비용은 entity 생성/삭제/transform 변경으로
snapshot revision이 바뀔 때만 발생한다. 100K의 400 draw call은 16×16 render chunk의 비용이며, 다음 실험에서
32×32와 64×64를 비교해 culling 정밀도와 draw call을 조정한다.

렌더 원본 CSV는 `native/benchmarks/latest_render_benchmark.csv`에 있다.
